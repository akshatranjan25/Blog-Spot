# MegaBlog - Modern Blogging Platform

A full-featured blogging platform built with React and Appwrite, featuring a modern UI, smooth animations, and robust functionality.

![MegaBlog Screenshot](src/assets/blog-svgrepo-com.svg)

## 🚀 Features

### Authentication
- User registration and login
- Secure password handling
- Session management
- Protected routes

### Blog Management
- Create, read, update, and delete blog posts
- Rich text editor with TinyMCE
- Image upload and management
- Post status management (active/inactive)

### User Experience
- Modern and responsive design
- Smooth animations using Framer Motion
- Loading states and error handling
- Intuitive navigation

### Content Management
- Rich text editing with formatting options
- Image upload and preview
- Slug generation
- Post categorization

## 🛠️ Tech Stack

### Frontend
- **React** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **React Hook Form** - Form handling
- **TinyMCE** - Rich text editor
- **Redux Toolkit** - State management

### Backend
- **Appwrite** - Backend as a Service
  - Authentication
  - Database
  - Storage
  - File management

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/akshatranjan25/Blog-Spot.git
```

2. Install dependencies:
```bash
cd Blog-Spot
npm install
```

3. Set up environment variables:
Create a `.env` file in the root directory with your Appwrite configuration:
```env
VITE_APPWRITE_URL=your_appwrite_url
VITE_APPWRITE_PROJECT_ID=your_project_id
VITE_APPWRITE_DATABASE_ID=your_database_id
VITE_APPWRITE_COLLECTION_ID=your_collection_id
VITE_APPWRITE_BUCKET_ID=your_bucket_id
```

4. Start the development server:
```bash
npm run dev
```
